# 轮腿机器人动力学建模文档

> 本文档基于 `LQR.m`（MATLAB 动力学推导与 LQR 增益求解）和 `others/Motion_Control/` 下的用户控制代码整理，
> 精确描述本五连杆轮腿机器人的**机械结构**、**运动学**与**动力学关系**。
> 文档忽略 CubeMX 自动生成代码，只覆盖用户编写的算法部分。
>
> 全机模型由两套相互衔接的子模型构成：
> 1. **VMC 五连杆模型**（`VMC.c`）——描述真实机械结构，做关节空间 ↔ 虚拟腿空间的运动学/静力学映射。
> 2. **LQR 轮腿动力学模型**（`LQR.m` / `lqr_calculate.c`）——把整机简化为"轮子 + 虚拟腿杆 + 机体"的平面欠驱动倒立摆，用于平衡控制。
>
> 两者通过**虚拟腿** $(L_0,\ \phi_0)$ 与**虚拟力** $(F,\ T)$ 这一对物理量衔接：LQR 输出虚拟腿杆力矩，VMC 把它解算成两个髋关节电机的实际力矩。

## 1. 整机机械结构

本机器人为**双轮足（Wheel-Leg）平衡机器人**，左右各一条腿，每条腿为**平面五连杆机构（VMC 五连杆）**，腿末端装驱动轮。整机自由度配置：

| 部件 | 数量 | 执行器 | 作用 |
|------|------|--------|------|
| 髋关节电机 | 4（左右各 2） | DM8009（达妙关节电机） | 驱动五连杆，控制腿长 $L_0$ 与腿摆角 $\phi_0$ |
| 驱动轮电机 | 2（左右各 1） | DJ3508（M3508） | 提供前进/平衡/转向力矩 $T_w$ |
| 氮气弹簧 | 每腿 1 | 被动 | 沿腿杆方向提供被动支撑力，减轻电机负担 |

### 1.1 单腿五连杆几何

每条腿是一个**对称平面五连杆**，五根连杆长度在 `chassis_initializer.cpp::ChassisInitializer::InitializeVmc()` 中赋值：

```c
// VMC_Init(VMC, l1, l2, l3, l4, l5, isLeft)
VMC_Init(&VMC_L, 0.210f, 0.250f, 0.250f, 0.210f, 0.0f, 1);  // 左腿
VMC_Init(&VMC_R, 0.210f, 0.250f, 0.250f, 0.210f, 0.0f, 0);  // 右腿
```

| 连杆 | 符号 | 长度 (m) | 说明 |
|------|------|----------|------|
| 大腿（近 $\phi_1$ 侧） | $l_1$ | 0.210 | 与 $\phi_1$ 关节电机相连的连杆 |
| 小腿（近 $\phi_1$ 侧） | $l_2$ | 0.250 | $l_1$ 末端 B 到足端 C 的连杆 |
| 小腿（近 $\phi_4$ 侧） | $l_3$ | 0.250 | $l_4$ 末端 D 到足端 C 的连杆 |
| 大腿（近 $\phi_4$ 侧） | $l_4$ | 0.210 | 与 $\phi_4$ 关节电机相连的连杆 |
| 机架（两关节间距） | $l_5$ | **0.0** | 单腿两个髋关节电机转轴的水平间距 |

> **重要结构特征**：$l_5 = 0$ 意味着**同一条腿**的两个髋关节电机（$\phi_1$、$\phi_4$）**机械同轴**——共用同一条转轴、同一旋转中心 $A$。因此该腿的平面五连杆退化为"以公共轴 $A$ 为顶点的一对对称双摆杆"：足端 $C$ 由两条 2-连杆链 $A\!-\!B\!-\!C$（$l_1,l_2$）与 $A\!-\!D\!-\!C$（$l_4,l_3$）共同确定（菱形的上顶点收为一点）。$l_1 = l_4 = 0.210$、$l_2 = l_3 = 0.250$，机构左右对称。
>
> **注意两个"左右"不要混淆**：
> - $l_5$ 描述的是**单腿内部**两个驱动关节的关系（同轴）。
> - 整车有**两条独立的腿**，分处车体左右两侧（沿机体 y 轴间隔 $2R_l = 0.385$ m，见 [§6](#6-lqr-平面动力学模型)），各自有自己的一套五连杆和驱动轮。
> - 正常运行时，左右两条腿在矢状面内**各自保持竖直**（虚拟腿角 $\phi_0 \approx \pi/2$，腿杆指向正下方），由**防劈叉控制**（AntiSplit，[§9](#9-完整控制数据流)）主动维持，**不会**出现一条腿往前、一条腿往后的"劈叉"姿态。

> **传动原理（一对电机 → 两个自由度）**：每条腿是**标准平行五连杆**——两个 DM8009 髋关节电机**各自独立驱动一根大腿**（$l_1$ 由一个电机、$l_4$ 由另一个电机），两根大腿在公共输出轴 $A$ 上同轴铰接但**各自独立转动**（"输出轴重合"即两铰点重合于一点，$l_5=0$；并非齿轮差动器）。
> 这根公共输出轴因此承载**两个自由度**，二者由这**同一对电机协同运动**产生，机械上并未预先解耦：
> - 两电机**同向**转动 → 整条腿绕 $A$ **摆动**，改变虚拟腿摆角 $\phi_0$（对应虚拟杆力矩 $T$）；
> - 两电机**反向/差动**转动 → 五连杆**张合**，改变虚拟腿长 $L_0$（对应沿腿方向的足端力 $F$）。
>
> **关键推论**：腿长（$L_0$/力 $F$）与腿摆（$\phi_0$/力矩 $T$）**复用同一对电机**，没有独立的伸缩电机。因此 $F$ 与 $T$ **共享两个电机的力矩预算**——这一执行器层面的耦合与约束是后续 roll 控制（靠左右腿差动 $F$）和力矩饱和分析的物理前提。$(F,T)\to(\tau_1,\tau_2)$ 的具体映射见 [§4 力雅可比](#4-vmc-静力学力雅可比)。


**单腿五连杆**（侧视，矢状面内；两髋关节同轴于 $A$）：

```
            机体 (body)
        ┌───────────────┐
        │       A        │   ← 单腿两髋关节电机同轴中心 (φ1、φ4 共轴, l5=0)
        │      ╱ ╲       │      DM8009 ×2 驱动同一条腿
        │  l1 ╱   ╲ l4   │
        │    ╱     ╲     │
        │   B       D    │   ← l1、l4 末端
        │    ╲     ╱     │
        │  l2 ╲   ╱ l3   │
        │      ╲ ╱       │
        │       C        │   ← 足端（虚拟腿末端 / 轮心）
        │       ●        │
        │      (轮)       │   ← DJ3508 驱动轮
        └───────────────┘

虚拟腿：从髋轴 A（即 l5/2 处）指向足端 C 的等效连杆，
       长度 L0，与机体水平的夹角 φ0；正常运行 φ0≈π/2（竖直）。
```

**整车两腿布局**（后视，冠状面；左右腿各自竖直，不劈叉）：

```
          机体 (body)
   ┌──────────────────────┐
   │                      │
   │  A_L            A_R   │  ← 左/右腿各自的髋关节轴
   │  │              │     │
   │  │L0_L          │L0_R │  ← 两腿都竖直 (φ0≈π/2)
   │  │              │     │
   │ (轮)          (轮)    │
   └──┴──────────────┴─────┘
   ←──── 2·R_l = 0.385 m ───→   (轮距)
```


### 1.2 虚拟腿（Virtual Leg）

VMC 的核心思想是把复杂的五连杆**等效成一根可伸缩的虚拟腿**：

- **虚拟腿长 $L_0$**：髋关节中点 $(l_5/2,\ 0)$ 到足端 $C$ 的距离。
- **虚拟腿摆角 $\phi_0$**：虚拟腿相对机体坐标系水平轴的夹角。
- 在虚拟腿上定义一对广义力：**沿腿方向的足端力 $F$**（推/拉腿，控制 $L_0$）和**垂直腿方向的虚拟杆力矩 $T$**（摆腿，控制 $\phi_0$）。

> $L_0$ 与 $\phi_0$ 是公共输出轴的**两个自由度**，由**同一对 DM8009 电机协同**产生（同向→摆、差动→伸缩，详见 [§1.1 传动原理](#11-单腿五连杆几何)）。因此虚拟空间里看似独立的 $F$（控腿长）与 $T$（控腿角）在执行器层面被**同一对电机的力矩 $(\tau_1,\tau_2)$ 耦合**，并共享其力矩上限。

LQR 控制器只面向虚拟腿杆工作（输出 $T$），VMC 负责把 $(F, T)$ 翻译成两个实际髋关节电机力矩 $(\tau_1, \tau_2)$。$F$ 不在 LQR 状态空间内，而是由腿长 PID + 重力前馈（+ roll 差动）单独算出后，与 $T$ 一起经力雅可比 $M$ 下发（见 [§4.1](#41-正向映射-ft-rightarrow-tau_1-tau_2)）。

## 2. 坐标系与符号定义

### 2.1 坐标系

| 坐标系 | 来源 | 说明 |
|--------|------|------|
| **机体系 (body)** | IMU | 固连于机体；VMC 内部 $\phi_0$、$\phi_1\!\sim\!\phi_4$ 均在此系。`accel_b[3]` 为机体系运动加速度 |
| **世界/大地系 (n)** | IMU 姿态解算 | 重力对齐的惯性系；`accel_n[3]` 为世界系加速度，腿摆角 $b\_\phi_0$、车速估计在此系 |
| **自然坐标系** | LQR 推导 | `LQR.m` 中状态 $s,\ \phi,\ \theta$ 所在的水平-竖直惯性系，等价于世界系 |

IMU 输出（`imu_temp_ctrl.c`）：

```c
float roll, pitch, yaw;   // 欧拉角，单位 °
float accel_b[3];         // 机体坐标系运动加速度（已去重力）
float accel_n[3];         // 世界坐标系运动加速度
```

- `pitch_trans[0]` = $\text{pitch} \times \pi/180$，机体俯仰角（rad），`pitch_trans[1]` 为上一帧。
- 控制周期统一为 **0.002 s（500 Hz）**，所有差分/积分都基于此周期。

### 2.2 关节角与虚拟腿角

| 符号 | 代码变量 | 含义 |
|------|----------|------|
| $\phi_1$ | `VMC->phi1` | 近 $l_1$ 侧髋关节角（机体系） |
| $\phi_4$ | `VMC->phi4` | 近 $l_4$ 侧髋关节角（机体系） |
| $\phi_2$ | `VMC->phi2` | $l_2$ 连杆姿态角（由闭链解算） |
| $\phi_3$ | `VMC->phi3` | $l_3$ 连杆姿态角（由闭链解算） |
| $\phi_0$ | `VMC->phi0` | **虚拟腿在机体系下的摆角** |
| $b\_\phi_0$ | `VMC->b_phi0` | **虚拟腿在大地系下的摆角**（= 机体系 $\phi_0$ 经 pitch 补偿） |

关节角由电机反馈位置映射（`VMC_Coculate()`）：

```c
// 左腿：φ1 = L_DM8009[1].Position + π，  φ4 = L_DM8009[0].Position

```

## 3. VMC 五连杆运动学（正向解算）

> 实现：`VMC.c::VMC_Get_L0_phi0()`。
> 已知两个驱动关节角 $\phi_1, \phi_4$，求足端坐标、虚拟腿长 $L_0$、虚拟腿角 $\phi_0$，以及中间连杆角 $\phi_2, \phi_3$。

### 3.1 关节点坐标

设髋关节中心 $A$ 为原点。$B$ 为 $l_1$ 末端，$D$ 为 $l_4$ 末端（$l_4$ 起点在 $(l_5, 0)$）：

$$
\begin{aligned}
X_B &= l_1 \cos\phi_1, & Y_B &= l_1 \sin\phi_1 \\
X_D &= l_4 \cos\phi_4 + l_5, & Y_D &= l_4 \sin\phi_4
\end{aligned}
$$

```c
VMC->Xb = VMC->l1 * cos(VMC->phi1);
VMC->Xd = VMC->l4 * cos(VMC->phi4) + VMC->l5;
VMC->Yb = VMC->l1 * sin(VMC->phi1);
VMC->Yd = VMC->l4 * sin(VMC->phi4);
```

### 3.2 闭链求解 $\phi_2$（足端 C 位置）

足端 $C$ 是以 $B$ 为圆心、$l_2$ 为半径与以 $D$ 为圆心、$l_3$ 为半径两圆的交点。代码用半角公式法求 $\phi_2$：

先求 $BD$ 连线相关中间量：

$$
\begin{aligned}
A_0 &= 2\, l_2 (X_D - X_B) \\
B_0 &= 2\, l_2 (Y_D - Y_B) \\
L_{BD} &= \sqrt{(X_D-X_B)^2 + (Y_D-Y_B)^2} \\
C_0 &= l_2^2 + L_{BD}^2 - l_3^2
\end{aligned}
$$

再由
$$
\phi_2 = 2 \arctan\!\left( \frac{B_0 + \sqrt{A_0^2 + B_0^2 - C_0^2}}{A_0 + C_0} \right)
$$

```c
VMC->A0  = 2*l2*(Xd - Xb);
VMC->B0  = 2*l2*(Yd - Yb);
L_BD     = sqrt((Xd-Xb)^2 + (Yd-Yb)^2);
VMC->C0  = l2^2 + L_BD^2 - l3^2;
a = sqrt(A0^2 + B0^2 - C0^2);
phi2 = 2 * atan2(B0 + a, A0 + C0);
```

### 3.3 足端坐标与 $\phi_3$

$$
\begin{aligned}
X_C &= l_1 \cos\phi_1 + l_2 \cos\phi_2 \\
Y_C &= l_1 \sin\phi_1 + l_2 \sin\phi_2 \\
\phi_3 &= \arctan2\big(Y_B - Y_D + l_2\sin\phi_2,\ \ X_B - X_D + l_2\cos\phi_2\big)
\end{aligned}
$$

### 3.4 虚拟腿长 $L_0$ 与腿角 $\phi_0$

虚拟腿从髋中点 $(l_5/2,\ 0)$ 指向足端 $C$：

$$
\boxed{\,L_0 = \sqrt{\left(X_C - \tfrac{l_5}{2}\right)^2 + Y_C^2}\,}
\qquad
\boxed{\,\phi_0 = \arctan2\!\left(Y_C,\ X_C - \tfrac{l_5}{2}\right)}
$$

```c
L0   = sqrt((Xc - l5/2)^2 + Yc^2);
phi0 = atan2(Yc, Xc - l5/2);
```

### 3.5 速度/加速度（数值差分 + 一阶 IIR 滤波）

所有微分量用前向差分（$\Delta t = 0.002$ s）后经一阶低通滤波：

$$
\dot{\phi}_0 = \alpha_{d\phi_0}\frac{\phi_0 - \phi_0^{-}}{0.002} + (1-\alpha_{d\phi_0})\dot{\phi}_0^{-}
$$
$$
\dot{L}_0 = \frac{L_0 - L_0^{-}}{0.002}, \qquad
\ddot{L}_0 = \frac{\dot{L}_0 - \dot{L}_0^{-}}{0.002}, \qquad
\ddot{L}_{0,f} = \alpha_{ddL_0}\ddot{L}_0 + (1-\alpha_{ddL_0})\ddot{L}_{0,f}
$$

滤波系数：`alpha_d_phi0=1.0`、`alpha_phi0=1.0`、`alpha_dd_L0=0.1`、`alpha_dd_b_phi0=0.1`。

### 3.6 大地系腿角 $b\_\phi_0$（pitch 补偿）

虚拟腿在大地系下的摆角需扣除机体俯仰，且左右腿映射不同（镜像）：

$$
\begin{aligned}
\text{左腿：}\quad b\_\phi_0^{L} &= -\text{pitch} + \phi_0^{L} - \tfrac{\pi}{2} \\
\text{右腿：}\quad b\_\phi_0^{R} &= -\text{pitch} + (\pi - \phi_0^{R}) - \tfrac{\pi}{2}
\end{aligned}
$$

```c
// 左
VMC_L.b_phi0 = -pitch_trans[0] + VMC_L.phi0 - (PI/2);
// 右（注意 π - phi0 的镜像）
VMC_R.b_phi0 = -pitch_trans[0] + (PI - VMC_R.phi0) - (PI/2);
```

> $b\_\phi_0$ 即 LQR 模型中的腿摆角 $\theta_l$（腿杆与竖直方向 z 轴的夹角），是平衡控制最关键的反馈量。竖直站立时 $b\_\phi_0 \approx 0$。

## 4. VMC 静力学（力雅可比）

> 实现：`VMC.c::VMC_Set_F0_T()` 与逆映射 `VMC_Solve_F_T_From_Torque()`。
> 把虚拟腿广义力 $(F, T)$ 映射到两个髋关节电机力矩 $(\tau_1, \tau_2)$。

### 4.1 正向映射 $(F,T) \rightarrow (\tau_1, \tau_2)$

由虚功原理 $\boldsymbol{\tau} = J^{\mathsf T} \begin{bmatrix} F \\ T \end{bmatrix}$，力雅可比转置矩阵 $M$ 的四个元素为：

$$
\begin{aligned}
\tau_1 &= \underbrace{\frac{l_1 \sin(\phi_0 - \phi_3)\sin(\phi_1 - \phi_2)}{\sin(\phi_3 - \phi_2)}}_{m_{00}} F
        + \underbrace{\frac{l_1 \cos(\phi_0 - \phi_3)\sin(\phi_1 - \phi_2)}{L_0 \sin(\phi_3 - \phi_2)}}_{m_{01}} T \\[2mm]
\tau_2 &= \underbrace{\frac{l_4 \sin(\phi_0 - \phi_2)\sin(\phi_3 - \phi_4)}{\sin(\phi_3 - \phi_2)}}_{m_{10}} F
        + \underbrace{\frac{l_4 \cos(\phi_0 - \phi_2)\sin(\phi_3 - \phi_4)}{L_0 \sin(\phi_3 - \phi_2)}}_{m_{11}} T
\end{aligned}
$$

即
$$
\begin{bmatrix} \tau_1 \\ \tau_2 \end{bmatrix}
= \underbrace{\begin{bmatrix} m_{00} & m_{01} \\ m_{10} & m_{11} \end{bmatrix}}_{M}
\begin{bmatrix} F \\ T \end{bmatrix}
$$

```c
matrix[0] = (l1*sin(phi0-phi3)*sin(phi1-phi2)) / sin(phi3-phi2);          // m00
matrix[1] = (l1*cos(phi0-phi3)*sin(phi1-phi2)) / (L0*sin(phi3-phi2));     // m01
matrix[2] = (l4*sin(phi0-phi2)*sin(phi3-phi4)) / sin(phi3-phi2);          // m10
matrix[3] = (l4*cos(phi0-phi2)*sin(phi3-phi4)) / (L0*sin(phi3-phi2));     // m11
VMC->T1 = matrix[0]*F + matrix[1]*T;   // φ1 关节电机力矩
VMC->T2 = matrix[2]*F + matrix[3]*T;   // φ4 关节电机力矩
```

### 4.2 氮气弹簧补偿

足端力指令 $F$ 在下发前先扣除氮气弹簧被动力，再一阶滤波：

$$
F \leftarrow \alpha_F\big(F_{\text{cmd}} - F_{\text{gas}}(L_0)\big) + (1-\alpha_F)F^{-},\qquad \alpha_F = 0.5
$$

氮气弹簧力由三次多项式拟合（实验标定，`Gas_Spring.c`，$y = L_0 \times 1000$ 为 mm）：

$$
\boxed{\,F_{\text{gas}}(L_0) = 2.44\times10^{-6}\,y^3 - 2.80\times10^{-3}\,y^2 + 1.043\,y - 34.66\ \ [\text{N}]\,}
$$

> 弹簧力随腿长增大而增大，方向沿腿杆向外（支撑）。`gas_spring_enable=1` 时启用（`chassis_initializer.cpp`）。

### 4.3 逆向映射 $(\tau_1, \tau_2) \rightarrow (F, T)$

用于由电机**实际反馈力矩**反解实际足端力（求逆 $M^{-1}$）：

$$
\det M = m_{00}m_{11} - m_{01}m_{10}
$$
$$
F_{\text{actual}} = \frac{m_{11}\tau_1 - m_{01}\tau_2}{\det M}, \qquad
T_{\text{actual}} = \frac{-m_{10}\tau_1 + m_{00}\tau_2}{\det M}
$$

> 当腿伸/缩到极限位姿（$|\det M| < 10^{-6}$）矩阵奇异，代码回退到指令值 $F + F_{\text{gas}}$、$T$ 以避免发散。

### 4.4 重力补偿前馈

常态下，足端力指令由 `balance_controller.cpp` 在腿长 PID 输出基础上叠加重力前馈：

$$
F = \underbrace{\text{PID}_{L_0}}_{\text{腿长闭环}} + \underbrace{\frac{mg}{\cos(b\_\phi_0)}}_{\text{重力前馈}} \pm \underbrace{\text{PID}_{\text{roll}}}_{\text{横滚补偿}}
$$

其中 `mg = 60.0/2 = 30 N`（单腿承担半机重），$1/\cos(b\_\phi_0)$ 把竖直重力投影到腿杆方向。横滚补偿左腿取 $+$、右腿取 $-$。

## 5. 地面支持力估计与离地观测

> 实现：`VMC.c::VMC_Get_Ground_F0()` 与 `off_ground_detector.cpp`。
> 这是整机**竖直方向动力学**的显式建模，用于离地检测。

### 5.1 足端总力沿竖直方向的分量 P

由电机反馈力矩反解出 $F_{\text{actual}}, T_{\text{actual}}$，加回氮气弹簧力得足端总力 $F_{\text{total}}$，再投影到竖直方向：

$$
F_{\text{total}} = F_{\text{actual}} + F_{\text{gas}}(L_0)
$$
$$
\boxed{\,P = F_{\text{total}} \cos(b\_\phi_0) + \frac{T_{\text{actual}} \sin(b\_\phi_0)}{L_0}\,}
$$

> 第一项是沿腿力 $F$ 的竖直分量，第二项是虚拟杆力矩 $T$ 通过力臂 $L_0$ 产生的竖直分力。

### 5.2 轮心竖直加速度

轮心 $z_w$ 由机体竖直加速度叠加腿伸缩 + 腿摆动的运动学合成（对 $z_w = z_{\text{body}} - L_0\sin(\cdot)$ 类几何关系求二阶导）：

$$
\ddot{z}_w = a_{n,z}
- \ddot{L}_{0,f}\cos(b\_\phi_0)
+ 2\dot{L}_0\dot{b}\_\phi_0\sin(b\_\phi_0)
+ L_0\,\ddot{b}\_\phi_{0,f}\sin(b\_\phi_0)
+ L_0\,\dot{b}\_\phi_0^2\cos(b\_\phi_0)
$$

```c
float dd_zw = accel_n[2]
    - dd_L0_f * cos(b_phi0)
    + 2*d_L0*d_b_phi0 * sin(b_phi0)
    + L0*dd_b_phi0_f * sin(b_phi0)
    + L0*d_b_phi0*d_b_phi0 * cos(b_phi0);
```

### 5.3 地面支持力（牛顿第二定律，竖直方向）

对驱动轮（支持力模型用等效质量 `WHEEL_MASS`）沿竖直方向应用牛顿第二定律：

$$
\boxed{\,F_N = P + m_{w,\text{eq}}\,(g + \ddot{z}_w)\,}, \qquad m_{w,\text{eq}} = 1.1\ \text{kg}（两轮总质量）,\ g = 9.81\ \text{m/s}^2
$$

```c
return P + WHEEL_MASS * (GRAVITY_ACC + dd_zw);   // WHEEL_MASS=1.1, GRAVITY_ACC=9.81
```

> 注意 `WHEEL_MASS=1.1 kg` 是**两轮总质量**，与 LQR 模型中的单轮质量 $m_w=0.615$ kg 不是同一量（见 [§10.2](#102-质量与惯量)）。

### 5.4 离地判据

支持力经 $\alpha_{G}=0.1$ 低通滤波后，用迟滞计数器判定（`OffGroundDetector::Update()`）：

- $F_N \le 50$ N → 计数 `off_ground++`（上限 20）
- $F_N \ge 10$ N → 计数 `off_ground--`（下限 0）
- 计数 $\ge 10$ 判定该腿离地

离地后：该腿轮力矩清零（脱力）、腿归中（仅保留 $b\_\phi_0$ 阻尼项 $-K[2][4]\cdot b\_\phi_0 - K[2][5]\cdot\dot{b}\_\phi_0$，乘 0.7 收腿系数），并清零位移积分。

## 6. LQR 平面动力学模型

> 推导：`LQR.m` 第 42–97 行。
> 这是整机**平面（前进-俯仰-偏航）动力学**的核心，参考 2023 上交开源与哈工程开源建立。

### 6.1 模型简化与假设

整机在**矢状面（前进方向）**简化为三体系统（左右各一套"轮+腿"，共享机体）：

```
        机体 m_b, I_b          ← 倒立摆主体，质心在关节上方 l_c 处
          ║ (pitch θ_b)
    ══════╬══════  髋关节轴（左右腿同此轴，沿 y 向分置两侧）
          ║                    ← 腿杆 m_l, I_ll/I_lr，摆角 θ_ll/θ_lr
          ║                      正常运行两腿各自竖直 (θ_l≈0)
         (轮)                   ← 驱动轮 m_w, I_w，转角 θ_wl/θ_wr
 ═════════╧═════════  地面

侧视投影下左右腿重叠（均竖直）；左右独立建模用于差速转向（偏航 φ），
θ_l 是腿杆与竖直 z 轴的夹角，竖直站立时 θ_l≈0，非"劈叉"张角。
```


- 左右两套"轮 + 腿"，共享一个机体；左右独立建模允许差速转向（偏航 $\phi$）。
- 腿部参数 $l_{wl}, l_{bl}, I_{ll}$ **随腿长 $L_0$ 变化**（见 6.4 数据集），机体绕 z 轴惯量 $I_z$ 简化为常量。
- 轮子做纯滚动（无滑移），由观测器单独抑制打滑。

### 6.2 动力学方程组（拉格朗日法导出）

`LQR.m` 中 `eqn1`～`eqn5` 是机器人的 5 条耦合动力学方程，对应原文（上交开源）方程 (3.11)–(3.15)。未知二阶导为 $\ddot\theta_{wl}, \ddot\theta_{wr}, \ddot\theta_{ll}, \ddot\theta_{lr}, \ddot\theta_b$。

**方程 1（左轮-左腿耦合）：**
$$
\left(\frac{I_w l_l}{R_w} + m_w R_w l_l + m_l R_w l_{bl}\right)\ddot\theta_{wl}
+ (m_l l_{wl} l_{bl} - I_{ll})\ddot\theta_{ll}
+ \left(m_l l_{wl} + \frac{m_b l_l}{2}\right)g\,\theta_{ll}
+ T_{bl} - T_{wl}\left(1 + \frac{l_l}{R_w}\right) = 0
$$

**方程 2（右轮-右腿耦合）：** 与方程 1 镜像（下标 $l \to r$）。

**方程 3（前进方向平动）：**
$$
\begin{aligned}
&-\left(m_w R_w^2 + I_w + m_l R_w^2 + \frac{m_b R_w^2}{2}\right)(\ddot\theta_{wl} + \ddot\theta_{wr}) \\
&-\left(m_l R_w l_{wl} + \frac{m_b R_w l_l}{2}\right)\ddot\theta_{ll}
 -\left(m_l R_w l_{wr} + \frac{m_b R_w l_r}{2}\right)\ddot\theta_{lr}
 + T_{wl} + T_{wr} = 0
\end{aligned}
$$

**方程 4（机体俯仰）：**
$$
\begin{aligned}
&\left(m_w R_w l_c + \frac{I_w l_c}{R_w} + m_l R_w l_c\right)(\ddot\theta_{wl} + \ddot\theta_{wr})
+ m_l l_{wl} l_c\,\ddot\theta_{ll} + m_l l_{wr} l_c\,\ddot\theta_{lr} \\
&- I_b\,\ddot\theta_b + m_b g l_c\,\theta_b
- (T_{wl}+T_{wr})\frac{l_c}{R_w} - (T_{bl}+T_{br}) = 0
\end{aligned}
$$

**方程 5（偏航 / 差速转向）：**
$$
\begin{aligned}
&\left(\frac{I_z R_w}{2R_l} + \frac{I_w R_l}{R_w}\right)\ddot\theta_{wl}
- \left(\frac{I_z R_w}{2R_l} + \frac{I_w R_l}{R_w}\right)\ddot\theta_{wr} \\
&+ \frac{I_z l_l}{2R_l}\ddot\theta_{ll} - \frac{I_z l_r}{2R_l}\ddot\theta_{lr}
- T_{wl}\frac{R_l}{R_w} + T_{wr}\frac{R_l}{R_w} = 0
\end{aligned}
$$

```matlab
[ddtheta_wl, ddtheta_wr, ddtheta_ll, ddtheta_lr, ddtheta_b] = ...
    solve(eqn1, eqn2, eqn3, eqn4, eqn5, ...);   % 解出 5 个二阶导的符号表达式
```

## 7. 状态空间（A,B 矩阵）与控制律

### 7.1 11 维状态向量

> `LQR.m` 第 32 行 + `lqr_Q` 注释。完整状态用于 MATLAB 推导：

$$
\mathbf{x} = [\,s,\ \dot s,\ \phi,\ \dot\phi,\ \theta_{ll},\ \dot\theta_{ll},\ \theta_{lr},\ \dot\theta_{lr},\ \theta_b,\ \dot\theta_b,\ \textstyle\int\theta_b\,]^{\mathsf T}
$$

| 分量 | 含义 |
|------|------|
| $s,\ \dot s$ | 前进位移 / 速度（自然坐标系水平方向） |
| $\phi,\ \dot\phi$ | 偏航角 / 角速度 |
| $\theta_{ll},\ \dot\theta_{ll}$ | 左腿摆角（与竖直 z 轴夹角）/ 角速度 |
| $\theta_{lr},\ \dot\theta_{lr}$ | 右腿摆角 / 角速度 |
| $\theta_b,\ \dot\theta_b$ | 机体俯仰角 / 角速度 |
| $\int\theta_b$ | 俯仰角积分项（消除稳态俯仰误差） |

> 第 11 个状态 $\int\theta_b$ 是积分增广，对应 $A$ 矩阵第 11 行 $A(11,9)=1$（即 $\frac{d}{dt}\int\theta_b = \theta_b$）。

### 7.2 连续状态空间

$$
\dot{\mathbf{x}} = A\,\mathbf{x} + B\,\mathbf{u}, \qquad \mathbf{u} = [T_{wl}, T_{wr}, T_{bl}, T_{br}]^{\mathsf T}
$$

- $A \in \mathbb{R}^{11\times11}$，$B \in \mathbb{R}^{11\times4}$。
- 矩阵元素通过对 6.2 解出的二阶导表达式求**雅可比**（对状态 → $A$，对输入 → $B$），在工作点线性化得到（`LQR.m` 第 54–55 行 `jacobian(...)`）。
- $s$ 和 $\phi$ 由轮子转角和腿角线性组合还原：
  $$\ddot s = \frac{R_w}{2}(\ddot\theta_{wl} + \ddot\theta_{wr}), \qquad
    \ddot\phi = \frac{R_w(-\ddot\theta_{wl} + \ddot\theta_{wr})}{2R_l} - \frac{l_l\ddot\theta_{ll}}{2R_l} + \frac{l_r\ddot\theta_{lr}}{2R_l}$$
  （`LQR.m` 第 64–65、87–88 行的填充逻辑）。

### 7.3 LQR 权重矩阵

代价函数 $J = \int (\mathbf{x}^{\mathsf T} Q\,\mathbf{x} + \mathbf{u}^{\mathsf T} R\,\mathbf{u})\,dt$。

**$Q$ 对角元（`lqr_Q`）：**

| 状态 | $s$ | $\dot s$ | $\phi$ | $\dot\phi$ | $\theta_{ll}$ | $\dot\theta_{ll}$ | $\theta_{lr}$ | $\dot\theta_{lr}$ | $\theta_b$ | $\dot\theta_b$ | $\int\theta_b$ |
|------|-----|------|------|------|------|------|------|------|------|------|------|
| 权重 | 500 | 300 | 10000 | 1 | 5000 | 1 | 5000 | 1 | 25000 | 1 | 100 |

**$R$ 对角元（`lqr_R`）：** $T_{wl}, T_{wr}$ 各 40；$T_{bl}, T_{br}$ 各 5。

> 机体俯仰 $\theta_b$ 权重最高（25000），偏航 $\phi$ 次之（10000），体现"优先保持平衡和航向"。

### 7.4 Riccati 求解与增益拟合

通过 `icare()` 求解连续时间代数 Riccati 方程得到 $4\times11$ 增益矩阵 $K$：

$$
\mathbf{u} = -K\,\mathbf{x}, \qquad K = R^{-1}B^{\mathsf T}P
$$

由于 $K$ 随左右腿长 $(l_l, l_r)$ 变化，`LQR.m` 在 17×17 个腿长组合上求解 $K$，再对每个元素 $K_{ij}$ 做**二维二次多项式曲面拟合**：

$$
\boxed{\,K_{ij}(l_l, l_r) = p_{00} + p_{10}l_l + p_{01}l_r + p_{20}l_l^2 + p_{11}l_l l_r + p_{02}l_r^2\,}
$$

拟合系数存为 `K_Fit_Coefficients`（44×6，对应 $4\times11$ 增益矩阵的 44 个元素，每元素一行 6 个系数）。

### 7.5 嵌入式实现的 11 维状态与控制律

> 实现：`lqr_calculate.c`。

嵌入式端使用与模型一致的 **11 维状态**（位移/速度/偏航用实测误差量替代，$\int\theta_b$ 由俯仰积分 `int_pitch` 实现）：

$$
\mathbf{x} = [\,e_s,\ e_v,\ e_{yaw},\ \dot{yaw},\ b\_\phi_0^{L},\ \dot{b}\_\phi_0^{L},\ b\_\phi_0^{R},\ \dot{b}\_\phi_0^{R},\ \text{pitch},\ \dot{\text{pitch}},\ \textstyle\int\!\text{pitch}\,]^{\mathsf T}
$$

| 索引 | 变量 | 含义 |
|------|------|------|
| 0 | `body_distance_error` | 位移误差 $e_s$ |
| 1 | `speed_error` | 速度误差 $e_v$ |
| 2 | `yaw_error` | 偏航误差 $e_{yaw}$ |
| 3 | `d_yaw` | 偏航角速度 |
| 4,5 | `VMC_L.b_phi0`, `d_b_phi0` | 左腿大地系摆角及角速度 |
| 6,7 | `VMC_R.b_phi0`, `d_b_phi0` | 右腿大地系摆角及角速度 |
| 8 | `pitch_trans[0]` | 机体俯仰 |
| 9 | `d_pitch` | 俯仰角速度 |
| 10 | `int_pitch` | 俯仰角积分 $\int(\text{pitch}-\text{pitch}_{\text{off}})\,dt$（离地冻结，限幅 ±`int_pitch_limit`） |

**控制律**（`LQR_calculate()`）—— 4 路输出，每路是 11 维状态的加权和：

$$
\begin{aligned}

            - K_{0,4}(b\_\phi_0^L - \beta) - K_{0,5}\dot b\_\phi_0^L \\
          &\quad - K_{0,6}(b\_\phi_0^R - \beta) - K_{0,7}\dot b\_\phi_0^R
            + K_{0,8}(\text{pitch} - \text{pitch}_{\text{off}}) + K_{0,9}\dot{\text{pitch}} + K_{0,10}\textstyle\int\!\text{pitch} \\
T_{w}^{R} &= (\text{同上，第 1 行系数；} e_{yaw}\text{、}\dot{yaw}\text{ 符号相反实现差速}) \\
T_{\text{leg}}^{L} &= \text{第 2 行系数，} e_{yaw}\to -e_{yaw} \quad(\Rightarrow \text{Leg\_L\_T}) \\
T_{\text{leg}}^{R} &= \text{第 3 行系数，} e_{yaw}\to -e_{yaw} \quad(\Rightarrow \text{Leg\_R\_T})
\end{aligned}
$$

其中 $\beta$ = `b_phi0_offset = 0.2`（腿角平衡偏置），`pitch_off` = `pitch_offset_eff`（俯仰偏置，小陀螺时叠加 `PITCH_OFFSET_SPIN`）。$\int\!\text{pitch}$ = `int_pitch`，按 $\int(\text{pitch}-\text{pitch}_{\text{off}})\,dt$ 以 2 ms 步长累加，限幅 ±`int_pitch_limit`（默认 0.3）；任一腿离地时冻结（不累加、不复位），小陀螺时正常积分。

## 8. 车身速度、位移与姿态估计

### 8.1 单侧轮速 → 车身速度（正向运动学融合）

> 实现：`Wheel_Leg_about.c::Body_Speed_Coculate()`。

每侧车身速度 = 轮子滚动速度 + 腿摆动在水平方向的附加速度：

$$
\begin{aligned}
W_{L} &= \alpha_W(-\omega_{\text{motor}}^L + \dot b\_\phi_0^L) + (1-\alpha_W)W_L^{-} \\
v_{\text{body}}^L &= \alpha_{bs}\big(W_L R_w + \dot b\_\phi_0^L L_0^L \cos b\_\phi_0^L\big) + (1-\alpha_{bs})v_{\text{body}}^{L,-} \\
v_{\text{body}} &= \tfrac{1}{2}(v_{\text{body}}^L + v_{\text{body}}^R)
\end{aligned}
$$

> 物理意义：$W R_w$ 是轮心因轮子转动的速度；$\dot b\_\phi_0\,L_0\cos b\_\phi_0$ 是腿绕髋摆动使轮心额外平移的速度。$\alpha_W=0.9$，$\alpha_{bs}=1.0$。

### 8.2 轮端速度/加速度（差速 + 摆腿）

> 实现：`Wheel_End_Velocity.c::Wheel_End_Velocity_Both()`，半轮距 `HALF_TRACK_WIDTH = 0.19242 m`。

由质心运动经差速模型分解到左右髋，再叠加摆腿项：

$$
\begin{aligned}
v_{\text{hip}}^{L/R} &= v_{\text{body}} \mp \dot{yaw}\cdot R_l \\
v_{\text{wheel}}^{L/R} &= v_{\text{hip}}^{L/R} + \dot b\_\phi_0\,L_0\cos b\_\phi_0 \\
a_{\text{wheel}}^{L/R} &= a_{\text{hip}}^{L/R}
  + \ddot b\_\phi_0\,L_0\cos b\_\phi_0
  + \dot b\_\phi_0\,\dot L_0\cos b\_\phi_0
  - \dot b\_\phi_0^2\,L_0\sin b\_\phi_0
\end{aligned}
$$

加速度项即对 $v_{\text{wheel}}$ 求时间导（含科氏项 $\dot b\_\phi_0\dot L_0\cos$ 与向心项 $\dot b\_\phi_0^2 L_0\sin$）。$\ddot{yaw}$ 由 $\dot{yaw}$ 差分得到。

### 8.3 卡尔曼滤波车速

> 实现：`observe_task.c`，2 维状态 $[v, a]$ 卡尔曼滤波器，抑制打滑。

- 状态转移：$\begin{bmatrix}v\\a\end{bmatrix}_{k} = \begin{bmatrix}1 & 0.002\\0 & 1\end{bmatrix}\begin{bmatrix}v\\a\end{bmatrix}_{k-1}$
- 观测：速度测量 = `body_speed`（8.1），加速度测量 = $-a_{b}[1]$（机体系前向加速度）
- 噪声：$Q = \text{diag}(50,\ 0.005)$，$R = \text{diag}(10^6,\ 0.01)$（速度测量噪声极大 → 主要信任加速度积分）
- 输出 `kalman_body_speed`（死区 0.05 m/s 内归零）。

### 8.4 位移误差

$$
\begin{aligned}
\text{body\_distance} &\mathrel{+}= v_{\text{kalman}}\cdot 0.002 \\
\text{target\_body\_distance} &\mathrel{+}= (v_{\text{kalman}} + e_v)\cdot 0.002 \\
e_s &= \text{target\_body\_distance} - \text{body\_distance}
\end{aligned}
$$

### 8.5 姿态角速度

$$
\dot{\text{pitch}} = \alpha_{dp}\frac{\text{pitch} - \text{pitch}^{-}}{0.002} + (1-\alpha_{dp})\dot{\text{pitch}}^{-}
$$
$$
\dot{yaw} = \alpha_{dy}\frac{\Delta yaw_{\text{wrap}}}{0.002} + (1-\alpha_{dy})\dot{yaw}^{-}
$$

$\alpha_{dp}=1.0$，$\alpha_{dy}=0.8$，$\Delta yaw$ 做 $\pm\pi$ 环绕处理。

## 9. 完整控制数据流

下图为站立/常态主循环 `Standing()`（500 Hz）的完整控制链路：

```
┌─ 传感器 ──────────────────────────────────────────────────────────┐
│  IMU: pitch, yaw, roll, accel_b[], accel_n[]                       │
│  电机反馈: DM8009.Position/Torque ×4,  DJ3508.Velocity ×2          │
└────────────────────────┬──────────────────────────────────────────┘
                         ▼
┌─ 状态解算 ─────────────────────────────────────────────────────────┐
│  INS_Coculate()      → pitch_trans, d_pitch, d_yaw                 │
│  VMC_Coculate()      → L0, phi0, b_phi0, d_b_phi0 (§3)             │
│  Body_Speed_Coculate → body_speed (§8.1)                          │
│  observe_task (KF)   → kalman_body_speed (§8.3, 独立500Hz任务)     │
└────────────────────────┬──────────────────────────────────────────┘
                         ▼
┌─ 误差计算 ─────────────────────────────────────────────────────────┐
│  Yaw_Error_Coculate()→ yaw_error                                  │
│  Speed_Error_Set()   → speed_error  (功率/腿长限速, §Wheel_Leg)    │
│  Distance_Error_Set()→ body_distance_error (§8.4)                 │
└────────────────────────┬──────────────────────────────────────────┘
                         ▼
┌─ 腿长 / 姿态子控制 ────────────────────────────────────────────────┐
│  Roll_Comp()         → 横滚补偿 PID                                │
│  Leg_L0_Control()    → 双速率斜坡 + 腿长 PID (L/R_Leg_L0_PID)      │
│  AntiSplit (防劈叉)   → Kp/Kd 随 L0_avg 一维二次拟合                │
└────────────────────────┬──────────────────────────────────────────┘
                         ▼
┌─ LQR 主控制 ──────────────────────────────────────────────────────┐
│  LQR_Update_K()      → 按 L0 刷新 K 矩阵 (100Hz, §7.4)            │
│  PowerCtrl()         → 功率门控缩放                                │
│  LQR_calculate()     → Tw_L, Tw_R (轮力矩),                        │
│                        Leg_L_T, Leg_R_T (虚拟腿杆力矩 T) (§7.5)    │
└────────────────────────┬──────────────────────────────────────────┘
                         ▼
┌─ 力矩合成与下发 ───────────────────────────────────────────────────┐
│  L_leg_T_cmd = Leg_L_T + anti_split - 离心补偿(c·d_yaw²)           │
│  R_leg_T_cmd = -Leg_R_T + anti_split - 离心补偿                    │
│  BalanceController 合成 ChassisCommand:                           │
│    常态: F = PID_L0 + mg/cos(b_phi0) ± Roll  (§4.4)               │
│    跳跃: F = 200 N + mg/cos(b_phi0) ± Roll                        │
│    → 单一 CommitCommand → VMC_Apply_Chassis_Target → DM8009      │
│  Tw_L/R → DJ3508                                                  │
└────────────────────────┬──────────────────────────────────────────┘
                         ▼
┌─ 保护与模式切换 ───────────────────────────────────────────────────┐
│  OffGroundDetector::Update() → 离地脱力/归中 (§5)                 │
│  StepHitDetector::Update()    → 磕台阶检测（自动触发默认关闭）      │
│  TipProtectionController      → |pitch|>45° 连续10帧后保护250帧   │
└───────────────────────────────────────────────────────────────────┘
```
